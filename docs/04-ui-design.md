# 04 界面设计

## 1. 参考与原则

界面采用顶栏 + 左侧导航 + 每页独立资源的组织方式：

- pywebview 单窗口。
- 顶部栏放品牌、全局状态、主题/设置。
- 左侧导航由后端页面注册表生成。
- 每个页面独立目录：`web/pages/<id>/{index.html,page.js,page.css}`。
- 页面通过 `window.definePage(id, {init, destroy, ...})` 注册，主框架动态加载。
- 使用 layui 的组件与样式，外加自定义 CSS 变量支持深浅色。

原则：

1. **主控制台在应用内；网页模块可在目标标签页注入轻量控制面板**：面板只负责“本页开始/停止/接管”，用于明确绑定标签页，避免操作错页；详细日志仍在应用内。
2. **通用骨架 + 模块注入面板**：模块详情页由框架提供状态、动作、日志、统计；模块通过 `panel.js` 注入自定义区域。
3. **状态可见**：任何自动化都必须能看到“是否连接、在做什么、为什么停下”。
4. **危险动作显式**：停止、卸载、安装依赖等需要确认；提交类动作不提供自动按钮。
5. **可诊断**：错误信息带解决步骤与“打开日志/打开配置目录”。

## 3. 页面与导航

| 页面 ID | 标题 | 侧边栏 | 说明 |
| --- | --- | --- | --- |
| `home` | 首页 | 是 | 选择网页 → 模块/语音配置 → 大模型；底部显示状态与日志 |
| `apps` | 应用与插件 | 是 | 模块卡片、插件列表、安装 zip |
| `module` | 模块详情 | 否（从应用进入） | 通用骨架 + 模块面板 |
| `guide` | 操作指南 | 是 | 扩展/ADB/模型/模块使用/FAQ |
| `settings` | 设置 | 是 | 通用设置 + 插件/模块设置 |
| `logs` | 日志 | 是 | 全局事件、过滤、导出 |

导航由后端 `get_nav()` 返回；模块不直接加入侧边栏，避免应用增多后导航膨胀。最近使用的模块显示在侧边栏底部（前端 localStorage 记录）。

### 3.1 路由

- 使用 hash 路由：`#/home`、`#/apps`、`#/module/ucampus`、`#/guide`、`#/settings`、`#/logs`。
- 未知路由回退首页。
- 模块详情页需要参数 `module_id`；直接刷新时从 hash 恢复。
- 页面切换时调用上一页 `destroy()`，关闭其定时器/事件订阅。

## 4. 首页

首页只保留最常用的配置，其余选项放在模块详情页和设置页：

1. **选择要执行的网页**：U校园、智慧树等；卡片显示模块状态和所需能力。
2. **网页操作与点击节奏**：打开网站、启动/停止模块、模块详情和“更多配置”。若模块提供点击间隔/误差设置，只在这里显示这几项。
3. **语音样本**：模块声明 `media.tts` 且当前提供者为 KokoClone 时展开；可上传样本音频，或朗读页面示例文字现场录制。同时提示语音模型在“模型下载”页面获取，详细语音选项在“设置 → 克隆语音”。
4. **模型配置**：云端 API / 本地 Ollama 配置、连接测试和模型下载入口。

底部保留当前状态和操作日志。模块的完整设置位于模块详情页的“配置” Tab；语音、能力绑定等详细设置位于“设置”页面。Ollama 默认地址为 `http://localhost:11434/v1`，推荐模型为 `qwen2.5vl:7b`。

## 5. 应用与插件页

### 5.1 应用模块

卡片网格（每行 2–3 个）：

```text
┌──────────────────────────────────────────┐
│ [图标] U校园                  [网页]     │
│ 识别题目、听力转写、作答与回填            │
│ 状态：未运行 / 已连接浏览器               │
│ 能力：llm.chat  media.asr  media.tts ... │
│ [打开]  [启用 ✓]                         │
└──────────────────────────────────────────┘
```

- 平台徽章：`网页` / `手机` / `通用`。
- 状态点：未运行（灰）、运行中（绿）、等待（黄）、错误（红）、不可用（红）。
- 不可用卡片显示缺失能力/依赖，点击“详情”查看。
- 启用开关即时保存；禁用运行中的模块先停止。
- “打开”进入模块详情页。

### 5.2 插件

列表或紧凑卡片：

- 名称、版本、提供的能力、依赖状态、启用开关、设置入口。
- 同一能力多个提供者时，显示“当前绑定”标签。
- 能力绑定区也可在设置页统一调整。

### 5.3 安装

- “安装包…”按钮：文件选择（`.focpkg`/`.zip`）。
- 安装对话框：
  1. 包信息（名称、版本、作者、类型、大小、SHA256）。
  2. 提供能力 / 需要能力 / 缺失能力（红）。
  3. Python 依赖列表 + “允许安装依赖”复选框 + 风险提示。
  4. 按钮：取消 / 安装。
- 安装中显示进度/日志；失败显示错误码与日志路径。
- 安装完成后提示“需要重启应用生效”，提供“退出并重启”（v1 可只提示手动重启）。

卸载：确认框列出将删除的目录与保留的设置；内置包不显示卸载。

## 6. 模块详情页（通用骨架）

### 6.1 结构

```text
┌──────────────────────────────────────────────────────────────┐
│ [图标] U校园  v1.0.0   [网页]  状态：运行中                   │
│ 能力：llm.chat ✓  media.asr ✓  media.tts ✓  web.bridge ✓     │
│ [开始] [停止] [自定义动作…]                     [刷新] [日志] │
├──────────────────────────────────────────────────────────────┤
│ 状态卡：当前消息 / 进度 / 已答题数 / 跳过数 / 错误数           │
├──────────────────────────────────────────────────────────────┤
│ Tab: [运行状态] [模块面板1] [模块面板2] [日志]                 │
│                                                              │
│  通用运行状态：                                               │
│   - 当前阶段、最后更新时间                                  │
│   - 事件日志（滚动）                                         │
│   - 错误提示 + 解决建议                                      │
│                                                              │
│  模块面板：由 panel.js 渲染                                  │
└──────────────────────────────────────────────────────────────┘
```

### 6.2 通用骨架职责

- 拉取 `get_module_state(id)`，每秒刷新（页面不可见时暂停）。
- 拉取事件增量，过滤当前模块。
- 渲染开始/停止按钮：
  - 运行中：开始禁用，停止可用。
  - 未运行：开始可用。
  - 不可用：全部禁用并显示原因。
- 渲染 `actions()` 返回的自定义动作；`style=danger` 需确认。
- 渲染进度条、统计数字。
- 加载模块 panel：
  - 请求 `get_module_panels(id)`，返回 `{id,title,js_url,css_urls}`。
  - 动态插入 `<link>` 和 `<script>`；脚本调用 `window.FreeOCS.registerPanel(id, definition)`。
  - 切换到对应 Tab 时 `mount(el, ctx)`；离开时 `unmount()`。
  - 面板脚本只加载一次；模块切换/禁用时清理。
- 错误横幅：显示最近错误、时间、“复制错误”、“打开日志”。

### 6.3 面板上下文

```js
{
  moduleId: "ucampus",
  api: pywebview.api,              // 原始 API，谨慎使用
  getState: () => state,           // 最近一次模块状态
  invoke: (action, payload) => pywebview.api.module_invoke(moduleId, action, payload),
  onState: (cb) => ...,            // 订阅状态
  onEvent: (cb) => ...,            // 订阅事件
  toast: (msg, type) => ...,
  escape: (text) => ...,           // HTML 转义
  formatTime: (iso) => ...,
}
```

面板不得：

- 直接操作其他模块的状态。
- 在渲染循环中发起大量 API 调用。
- 使用 `innerHTML` 插入未转义的网页文本/模型输出。

### 6.4 默认日志 Tab

即使模块没有 panel，也提供：

- 当前模块事件流（时间、级别、消息）。
- 清空按钮（只清 UI，不清文件日志）。
- “打开日志文件”。

- `advanced` 字段默认折叠。
- `visible_when` 不满足时隐藏，但仍保留已保存值。
- 底部“打开配置目录”“导出设置（脱敏）”“导入设置”可后续实现。

### 7.2 核心 section

**界面**

| 启动页 | select | 首页 |
| 日志级别 | select（debug/info/warn/error） | info |

**大模型**

- 连接方式：云端 OpenAI 兼容 API 或本地 Ollama。

| API 地址 | OpenAI 兼容 base URL |
| API Key | password |
| 模型 | 文本模型名 |
| 温度 | 0–2 |
| 最大输出 | tokens |
| 超时 | 秒 |
| 额外请求头 | JSON（可选，高级） |

**浏览器自动化**

| 字段 | 说明 |

| 本地端口 | 默认 8765；修改后需同步扩展设置 |

| 启用页面 Agent | bool |
| 状态 | 只读：扩展版本、最后心跳、当前标签页 |
| 操作 | 打开扩展目录 / 打开浏览器扩展页 / 检测连接 |

**手机自动化**

| 字段 | 说明 |
| --- | --- |
| adb 路径 | 留空用 PATH |
| 设备序列号 | 留空自动选择唯一设备 |
| 点击随机偏移 | 像素 |
| dump 超时 | 秒 |
| 截图超时 | 秒 |
| OCR 兜底 | bool |

**能力绑定**

- 每个多提供者能力一行：能力名、当前提供者下拉、状态。
- 单提供者显示只读。
- 无提供者显示“未安装”，链接到安装说明。

**插件/模块 section**

- 由 manifest 或运行时注册；标题、字段、帮助均来自包。
- 插件 section 出现在“插件”分组；模块 section 出现在“模块”分组。
- 未启用/不可用包仍显示 section，但标注状态并禁用保存（避免配置无效）。

## 8. 操作指南页

指南页是产品的一部分，必须覆盖“从零到能跑”的每一步，并带动态状态检测。

### 8.1 浏览器扩展

Tabs：Chrome / Edge / Firefox。

Chrome/Edge 步骤：

1. 点击“打开扩展目录”，复制路径。
2. 地址栏打开 `chrome://extensions`（Edge：`edge://extensions`）。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择第 1 步的目录。
5. 回到本页点击“检测连接”。
6. 打开目标网页并登录；扩展图标应显示已连接。

Firefox 步骤：

1. 地址栏打开 `about:debugging#/runtime/this-firefox`。
2. 点击“临时载入附加组件”。
3. 选择扩展目录中的 `manifest.json`。
4. 注意：临时加载在浏览器重启后失效；v1 暂不提供签名安装包。
5. 点击“检测连接”。

页面按钮：

- “打开扩展目录”（`open_path`）。
- “打开浏览器扩展页”（`open_external`，按检测到的浏览器选择 URL）。
- “检测连接”（刷新 `get_bridge_status`）。
- “复制目录路径”。

常见问题：未检测到扩展、扩展已安装但页面未注入、HTTPS 页面无法连接、端口冲突、浏览器重启后失效。

### 8.2 手机 ADB

步骤：

1. 手机开启“开发者选项”和“USB 调试”。
2. 数据线连接，手机上允许调试授权。
3. 在本页点击“刷新设备”，应看到序列号与“已授权”。
4. 如使用无线调试：`adb pair` / `adb connect` 命令（按 Android 版本给出）。
5. 在设置中固定设备序列号（多设备时）。

动态状态：设备列表、授权状态、Android 版本、屏幕分辨率；失败时显示 `adb devices` 输出。

### 8.3 大模型

- 说明支持任意 OpenAI 兼容 `/chat/completions` 服务（DeepSeek、Ollama、vLLM、LM Studio 等）。
- 示例配置与“测试连接”。
- 提醒：智慧树复用已配置的 `llm.chat` 能力，不要求模型支持 function calling。
- 密钥只保存在本机；不上传。

### 8.4 媒体能力

- 语音转写：模型目录/下载命令（faster-whisper）；或切换云端 ASR。
- OCR：RapidOCR 安装说明/依赖；tesseract 兜底。
- 语音合成：系统语音 vs edge-tts vs OpenAI 兼容；中文语音建议。
- 每项显示当前绑定提供者与可用状态。

### 8.5 模块使用

每个已启用模块一节：

- U校园：打开课程页 → 登录 → 在应用内开始 → 观察日志；遇到提交页会停止，需手动提交。
- 智慧树：安装浏览器扩展 → 登录并打开智慧树页面 → 在应用内开始；默认在提交页停止。
- 明确智慧树“自动提交”设置默认关闭，只有用户主动开启后才会执行提交与确认。

### 8.6 常见问题（FAQ）

- 为什么开始按钮是灰的？
- 为什么停在“等待手动提交”？
- 听力转写失败怎么办？
- 模型返回无法匹配选项？
- 浏览器扩展连接不上？
- 手机 dump 超时/页面空白？
- 如何完全卸载并清除数据？

## 9. 日志页

- 全局事件流（可跨模块）。
- 过滤：包、级别、关键字、时间范围。
- 自动滚动开关；暂停时保留位置。
- 操作：清空 UI、打开日志文件、复制选中、导出（后续）。
- 大段错误默认折叠，点击展开堆栈。
- 日志中密码/Key 已脱敏。

## 10. 前端 API（pywebview）

`pywebview.api` 暴露扁平方法：

### 启动/导航

```text
get_bootstrap() -> {
  app: {name, version, platform, data_dir, config_dir, log_file},
  nav: [{id,title}],
  packages: [...],
  modules: [...],
  bridge: {...},
  settings_summary: {...},
  events_cursor: 0
}
get_nav()
get_home()
```

### 包管理

```text
list_packages() -> [PackageInfo]
get_package(id) -> PackageInfo
install_package_dialog() -> {ok, package?}   # 打开文件选择器
install_package(path) -> {ok, package?, needs_restart}
uninstall_package(id) -> {ok}
set_package_enabled(id, enabled) -> {ok}
```

### 模块

```text
list_modules() -> [ModuleInfo]
get_module(id) -> ModuleInfo
get_module_state(id) -> ModuleState
module_start(id) -> {ok, message?}
module_stop(id) -> {ok, message?}
module_invoke(id, action, payload) -> {ok, message?, data?}
get_module_panels(id) -> [{id,title,js_url,css_urls}]
```

### 设置

```text
get_settings_schema() -> [Section]
get_settings_values() -> {section: {key: value, __has_value?: bool}}
save_settings(section_id, values) -> {ok, saved}
reset_settings(section_id) -> {ok}
test_llm() -> {ok, detail, latency_ms}
```

### 事件/诊断

```text
get_events(after_seq, limit=200) -> {events, last_seq}
clear_events() -> {ok}
get_bridge_status() -> {...}
refresh_android_devices() -> [...]
open_path(path) -> {ok}
open_external(url) -> {ok}
choose_directory() / choose_file(extensions) -> {ok, path?}
```

约定：

- 所有方法返回 JSON 可序列化对象；错误用 `{ok:false, error, code?}` 而不是抛到 JS（除不可恢复错误）。
- 密码值永不出现在返回值中。
- 长任务（安装依赖、测试 LLM）在 Python 侧异步执行，前端轮询事件或专用状态；不要阻塞 API 调用超过 2 秒。

## 11. 事件轮询

- 前端每 800ms 调用 `get_events(last_seq)`。
- 模块详情页同时每 800ms 调用 `get_module_state(id)`。
- 页面隐藏（`document.hidden`）时暂停轮询，恢复时补拉。
- 事件缓冲区 2000 条；前端只保留当前页面需要的 500 条，避免 DOM 膨胀。
- 轮询失败连续 3 次显示“与后台失联”横幅，并停止自动滚动。

## 12. 主题与国际化

- 主题：CSS 变量 + `data-theme`；layui 组件覆盖。
- 默认浅色，支持深色、跟随系统（`prefers-color-scheme`）。
- i18n：`web/i18n/zh-CN.json` 默认；`en-US.json` 可增量翻译。
- 包提供的标题/说明使用 manifest 原文，不强制翻译。
- 模块面板自行处理文案；可通过 `FreeOCS.i18n.t()` 读取通用字符串。
- 日期时间使用本地时区；数字/文件大小本地化格式。

## 13. 可访问性与细节

- 所有按钮有 `aria-label`/可见文本；图标按钮有 tooltip。
- 键盘：Tab 顺序合理；Esc 关闭对话框；Enter 提交表单。
- 颜色对比度 ≥ 4.5:1；状态不只靠颜色，配文字。
- 错误信息可复制；日志中的路径可点击打开目录。
- 加载状态使用骨架屏/进度条，避免空白。
- 删除/卸载/安装依赖使用明确动词，不用“确定/取消”模糊文案。

页面脚本约定：

```js
window.definePage("apps", {
  async init() { ... },
  destroy() { ... },
  onEvent(event) { ... },       // 可选
  onStateChange(state) { ... }, // 可选
});
```

- `init` 在 `index.html` 注入后调用。
- `destroy` 在离开页面时调用，必须清理定时器/订阅。
- 页面脚本通过 `window.App`（导航、主题、toast）和 `window.API`（pywebview 封装）访问框架能力。
